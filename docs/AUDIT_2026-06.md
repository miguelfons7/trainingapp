# VIAcademy Exit Audit — 2026-06-23 (v1.2.2)

Comprehensive audit run as five parallel read-only deep-dives (Security/RLS, Correctness/data-integrity,
Architecture/dead-code/perf, Content/UX, Docs/ops), then cross-corroborated and verified. This is the
**live worklist** for successors — severity-ranked, deduplicated, with `file:line` and fix direction.
Companion: [`ENGINEERING_HANDBOOK.md`](ENGINEERING_HANDBOOK.md).

**Verdict:** healthy codebase for its size and threat model (~15 internal users; RLS is the boundary).
No security CRITICAL/HIGH. One correctness CRITICAL — **already fixed in v1.2.2** during this audit.
The real risks are operational: a content-unpublishing footgun, unbounded reads that will silently
truncate as data grows, stale fallbacks, and **zero backups** with seed/content living only in gitignored
dirs. Findings that surfaced independently in ≥2 agents are marked ⨯2/⨯3 (high confidence).

---

## Priority 0 — DONE during this audit
- **✅ FIXED v1.2.2 — DB-created quizzes rendered as completable lessons (CRITICAL, ⨯2).** `ModuleView` derived `isQuiz` from a hardcoded 6-id Set that never included the CMS-authored am-role quiz; it showed as an empty lesson with a completing button, so AMs could finish the program and earn the certificate without the exam. Fix: `isQuiz` now also honors `currentModule.contentType === 'quiz'` (`src/pages/ModuleView.tsx`). **Owner follow-up:** confirm the am-role quiz `module_content` row is *published with `quizData`* (query below) — if not, the fix now correctly *blocks* false completion but the exam shows "coming soon" until content is published.
  ```sql
  select module_id, status, jsonb_array_length(content->'quizData'->'multipleChoice') as mc
  from module_content where course_id='am-role' and module_id like '%quiz%';
  ```

## Performance (top 3, ~25–28% eager-bundle cut)
Eager first-load ≈ 860KB min / ~235KB gzip = `index` 461KB + supabase-js 198KB (irreducible; the "loader-circle" chunk name is a red herring — it's supabase-js, and icons ARE tree-shaken) + framer-motion 120KB + preload helper 42KB.
1. **Move framer-motion off the critical path** (−120KB/−39KB gz): replace `motion` in the 3 eager consumers — ExpandableCard (→ CSS grid-rows/max-height), CompletionToast, ProgressBar. Then it only loads in lazy section/quiz chunks.
2. **Lazy-load QuizBlock + delete orphaned FinalExam** (−70–90KB): `ModuleView` statically imports QuizBlock which statically bundles all 5 course quiz datasets; render it behind `lazy()` in the existing `isQuiz` branch (Suspense fallback already there).
3. **Lazy the remaining eager pages** (−40–60KB): UserProfile, Certificates, CertificateView, Acknowledgements — same `lazy()` pattern as the 8 admin pages.
